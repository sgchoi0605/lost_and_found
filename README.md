# Lost & Found

분실·습득 신고와 물품 인계를 위한 팀 프로젝트입니다. HTML·CSS·JavaScript, Vite, Express, SQLite를 사용합니다.

## 빠른 실행

Node.js 22.13 이상에서 프로젝트 폴더의 터미널로 실행하세요.

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm db:init
corepack pnpm start
```

http://127.0.0.1:3000 으로 접속합니다. 서버 종료는 **Ctrl+C**입니다.
