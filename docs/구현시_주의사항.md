# 구현 시 주의사항 — 미구현 기능 표시

버튼을 만들었지만 실제 기능이 없으면 클릭 시 **`구현 필요(역할:번호)`** 형식의 alert를 띄웁니다.
예: `구현 필요(A:1)`. 역할은 A/B/C/D이며, 번호는 프로젝트 전체에서 순차적으로 부여합니다.
파일 위치가 아니라 실제 기능 담당자를 적습니다. 메인 화면의 인계 신청도 D 담당입니다.

## 현재 번호 목록

| 번호 | 역할 | 위치 | 미구현 기능 |
|---|---|---|---|
| 1 | A | 로그인 | 로그인 인증 |
| 2 | A | 로그인 | 아이디 찾기 |
| 3 | A | 로그인 | 비밀번호 재설정 |
| 4 | A | 로그인 | 회원가입 |
| 5 | B | 분실 신고 | 신고 등록·저장 |
| 6 | C | 메인 | 실제 신고 검색 |
| 7 | D | 메인 | 인계 신청 |
| 8 | A | 메인 알림 서랍 | 매칭 알림 선택·읽음 처리 |
| 9 | A | 메인 알림 서랍 | 인계 알림 선택·읽음 처리 |

다음 번호는 **10**입니다. 추가 전에 이 표를 확인하고 A와 번호를 조율한 뒤 항목을 기록하세요. 이미 배정한 번호는 재사용하거나 다시 매기지 않습니다.
아이디 찾기·비밀번호 재설정은 기존 UI에 있던 버튼이며, 최종 구현 범위는 팀에서 합의합니다.

## 일반 버튼에 적용하기

담당 HTML에서 `data-unimplemented`에 역할과 번호를 적습니다.

```html
<button type="button" data-unimplemented="D:10">보관 기간 연장</button>
```

이 예시는 작성 방법이며 10번을 실제로 배정한 것은 아닙니다.
해당 화면의 `frontend/js/*.js` 맨 위에 공통 모듈을 한 번 import합니다.

```js
import "../../../../shared/frontend/js/unimplemented.js";
```

HTML은 해당 JS를 `type="module"`로 연결해야 합니다.

```html
<script type="module" src="./js/admin-storage.js"></script>
```

이제 버튼을 클릭하면 `구현 필요(D:10)`이 표시됩니다. 별도로 onclick이나 alert 이벤트를 추가하지 않습니다.
버튼처럼 사용하는 링크도 `data-unimplemented`를 붙일 수 있으며 미구현 표시가 있는 동안 이동은 차단됩니다.

## 제출 버튼에 적용하기

폼과 제출 버튼에 **같은 번호**를 적습니다. 폼의 `novalidate`는 입력칸이 비어 있어도 미구현 안내가 먼저 나오게 합니다.

```html
<form data-unimplemented="B:5" novalidate>
  <input name="itemName" required>
  <button type="submit" data-unimplemented="B:5">신고 등록하기</button>
</form>
```

공통 모듈이 클릭과 Enter 제출을 처리하고 기본 제출을 막습니다.
기존 submit/click 핸들러에서 성공 안내나 서버 요청을 실행하지 않도록 제거하거나 비활성화하세요. 공통 모듈은 다른 이벤트 핸들러까지 자동으로 중단시키지는 않습니다.

## 실제 구현을 완료했을 때

1. 버튼과 폼의 `data-unimplemented`를 모두 제거합니다.
2. 미구현 표시용 `novalidate`를 제거하고 필요한 입력 검증을 구현합니다.
3. 실제 이벤트·API 처리와 오류 안내를 연결합니다.
4. 클릭·Enter 제출·입력 오류 상황을 확인합니다.
5. 위 표에 완료 상태를 기록합니다. 같은 화면에 미구현 버튼이 남아 있다면 공통 import를 유지합니다.

로그인·신고 페이지로 이동, 홈·취소 이동, 알림 서랍 열기·닫기, 로컬 사진 선택처럼 이미 동작하는 UI에는 이 표시를 붙이지 않습니다.
현재 메인의 예시 카드 필터는 실제 검색으로 오해하지 않도록 alert로 대체했습니다. 물품·알림 내용은 여전히 고정 예시입니다.
공통 처리 코드는 A가 관리하는 `shared/frontend/js/unimplemented.js`에 있습니다. 팀원은 자신의 HTML 속성과 모듈 import만 추가하면 됩니다.
